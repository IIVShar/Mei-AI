Frequently Asked Questions

Everything you need to know about Mei AI architecture and usage.

Is my chat history or personal data stored on remote servers?

No. All chat messages, active app settings, and custom API keys are saved strictly inside your browser's local storage engine (LocalStorage). No user logs or personal telemetry are retained.

Do I need an API key to use Mei AI?

No API key is required by default. Mei AI utilizes intelligent multi-model routing across open endpoints. However, if you prefer dedicated quotas, you can input your own Google Gemini or OpenRouter API key under Settings.

How does image generation work?

By toggling Image Mode in the prompt bar, your description is passed to high-resolution Flux image synthesis engines to render 1024x1024 artwork directly inside the workspace.
